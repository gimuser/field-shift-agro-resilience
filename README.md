# FIELD SHIFT
## AgroResilience — NASA Earth Observation for Climate-Smart Crop Rotation

A NASA Space Apps Challenge 2026 project.

### Mission
Build a decision-support platform that combines NASA Earth observations,
local soil information, crop characteristics, and farmer priorities to
explore resilient crop-rotation strategies.

### Current phase
Research and requirements validation.

**Important:** No agronomic recommendations or scientific scoring will
be implemented until the datasets, assumptions, and methodology have
been investigated and documented.

### Research documentation
1. Problem analysis
2. User requirements
3. NASA datasets
4. Agronomic methodology
5. System architecture
6. Development roadmap

### Project principles
- Traceable data sources
- Scientific transparency
- Explainable recommendations
- Explicit uncertainty
- Practical farmer-oriented design
