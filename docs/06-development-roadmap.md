# Development Roadmap

## Phase 1 — Understand
- Analyze the official challenge.
- Identify user needs.
- Validate datasets.
- Establish the pilot region.

## Phase 2 — Design
- Define the scientific methodology.
- Define functional requirements.
- Finalize architecture.
- Establish measurable acceptance criteria.

## Phase 3 — Build MVP
- Implement validated data access.
- Build farm profile and map.
- Implement transparent scenario comparison.
- Add explanations and uncertainty.

## Phase 4 — Validate
- Test data quality.
- Validate agronomic assumptions with reliable sources.
- Test usability and edge cases.

## Phase 5 — Demonstrate
- Prepare documentation.
- Prepare demo scenarios.
- Publish the final project and presentation.

## Rule
Do not begin application implementation until Phases 1 and 2
have produced reviewed decisions.
