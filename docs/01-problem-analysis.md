# Problem Analysis

## Challenge
Field Shift: Adapting Farms with NASA Data.

## Core objective
Investigate how NASA Earth observations, local soil information,
crop characteristics, and farmer priorities can support crop-rotation
decisions and farm resilience.

## Questions to investigate
- Which farming decisions are we helping farmers make?
- Which environmental risks matter most?
- What limitations do farmers face?
- What is the geographic scope of the first pilot?
- How will we measure whether the solution is useful?

## Open assumptions
To be validated through challenge research and stakeholder analysis.
