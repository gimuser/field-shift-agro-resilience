# User Requirements

## Primary users
To be validated: farmers, agricultural advisors, and researchers.

## Candidate capabilities
- Define a farm location and basic profile.
- Enter or import soil information.
- Explore environmental conditions.
- Define crop options and farmer priorities.
- Compare crop-rotation scenarios.
- Understand the evidence behind each result.

## Validation required
Confirm user needs, input availability, accessibility, and acceptance
criteria before implementation.
